# COOKY SURVIVORS ― 死に戻りサバイバーズ

ヴァンパイアサバイバーズ系 × ローグライク × 死に戻りメタ進行のブラウザゲーム。
ビルド不要の静的サイト(HTML+JS+Canvas)なので、**GitHub Pagesでそのまま公開できます**。

## 🌐 GitHub Pages で公開する手順

1. このリポジトリの **Settings → Pages** を開く
2. **Source**: `Deploy from a branch` を選択
3. **Branch**: 公開したいブランチ(`main` 等)/ フォルダは `/ (root)` を選択して **Save**
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

> スマホでも遊べます(画面左半分をタッチで仮想スティック、右下にスキルボタン)。

ローカルで試す場合はリポジトリ直下で:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

### ゲームサイクル

1. **周回**: 攻撃は自動。敵とオブジェクトを壊して「素材」と「コイン」を集める
2. **スキル**: Tabでゲームを止め、素材が揃ったスキルを取得。同じスキルは素材を集め直すたびレベルUP(レベルごとに強化内容が違う)
3. **仲間**: 倒した敵は一定確率で仲間になり、一緒に戦う(仲間にもHPがある)
4. **死亡**: 集めたコイン(+余り素材の換金)を持って「魂の広場」へ
5. **恒久強化**: 祭壇/研究所/宿舎/書庫でパワーアップ。新スキル解放・スキル上限解放・新素材解放も
6. **もっと遠くへ**: 敵は時間と初期地点からの距離で強くなる。周回を重ねて強化しないと先へは進めない

### 世界の広がり

- **基地**: 遠方にある旗の場所で8秒とどまると解放。魂の広場に**ワープゲート**が開き、次からそこから出撃できる。ゲートごとに**特別な恒久強化**も買える
- **港と船**: 大陸の沿岸8方位に港があり、それぞれ違う条件(コイン+素材)で壊れた船を修理すると海に出られる
- **海と大陸**: 敵には陸専用/海専用/両生がいて、仲間も同じ。乗船中、陸の仲間は港で待機(逆も同様)。海の先には強敵が待つ**別大陸**が複数
- **ヒーラー敵**: 回復役の敵は距離を保って逃げる。移動速度を強化して追い詰めろ。倒せば仲間になり、今度は君を回復してくれる
- **終焉の刻**: 30分を過ぎるとリーパーの大群が出現しほぼ強制ゲームオーバー。だが死に戻り強化を極めれば……その先へ

## 🖼 キャラ画像の差し替え

すべてのキャラは仮置きの自動生成スプライトです。
`assets/img/` にPNGを置くだけで差し替えられます。**→ 一覧と手順は [ASSETS.md](ASSETS.md)**

## 📁 構成

```
index.html      エントリ(UI DOM)
css/style.css   スタイル
js/data.js      全バランスデータ(素材/スキル/敵/メタ強化/基地/港)
js/sprites.js   仮置きスプライト生成+画像差し替え
js/audio.js     効果音シンセ
js/save.js      セーブ(localStorage)
js/input.js     キーボード+仮想スティック
js/world.js     オープンワールド地形/オブジェクト/ミニマップ
js/skills.js    周回内スキルシステム+パネルUI
js/run.js       周回シーン(戦闘・AI・船・港・基地)
js/hub.js       魂の広場(恒久強化・ワープ)
js/main.js      ゲームループ/状態管理
ASSETS.md       画像アセット一覧(差し替え用)
```

バランス調整はほぼ `js/data.js` だけで完結します。
