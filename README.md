# COOKY SURVIVORS ― 死に戻りサバイバーズ

ヴァンパイアサバイバーズ系 × ローグライク × 死に戻りメタ進行のブラウザゲーム。
ビルド不要の静的サイト(HTML+JS+Canvas)なので、**GitHub Pagesでそのまま公開できます**。

## 🌐 GitHub Pages で公開する手順

1. このリポジトリの **Settings → Pages** を開く
2. **Source**: `Deploy from a branch` を選択
3. **Branch**: 公開したいブランチ(`main` 等)/ フォルダは `/ (root)` を選択して **Save**
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

> スマホでも遊べます(画面左半分をタッチで仮想スティック、右下にスキルボタン)。

ローカルで試す場合はリポジトリ直下で:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

HUDには**危険度**(初期地点からの距離による敵の強さ)が表示されます。スキル画面は「強化/新規/効果一覧」のタブ+カテゴリタブ構成で、取得可能なものがあるタブには通知が出ます。

### ゲームサイクル

1. **周回**: 攻撃は自動(**攻撃手段は魂の広場の武器庫で選んだ1つ**)。敵とオブジェクトを壊して「素材」と「コイン」を集める(素材を拾うと画面左上に「◯◯を手に入れた」と表示。所持数はスキル画面の素材タブでいつでも確認できる)
2. **スキル**: Tabでゲームを止めると、**素材が揃ったスキルだけ**がリストに現れる(**仲間(軍勢)を育てるものが主体**: 庇護/先陣/鬨/軍医/不倒/同胞の心得、ウォーバナー、カリスマの歌など。主人公の攻撃関連は武器研磨・速撃の構えなど一部のみ)。同じスキルは素材を集め直すたびレベルUP(レベルごとに強化内容が違う)。**一度リストに現れたスキルは、素材が減っても・周回をまたいでも表示され続ける**
3. **仲間**: 倒した敵は一定確率(基礎20%・強い敵ほどなりにくい)で仲間になり、一緒に戦う(仲間にもHPがある)。**上限なし** ― 仲間は主人公の周りに**同心円の陣形**で付き従い(最初は密着、増えるほど輪が外へ広がる)、**陣形に触れた敵だけを迎撃**して深追いせず、主人公が反対方向へ動けば**その瞬間に戦闘をやめてついてくる**。画面は軍勢が全員映る大きさに自動ズーム。軍勢の壁で敵とぶつかる合戦
4. **死亡**: 集めたコイン(+余り素材の換金)を持って「魂の広場」へ
5. **恒久強化**: 祭壇/研究所/宿舎/書庫/**武器庫**でパワーアップ。画面隅の**施設マップ**でどこに何があるか一目でわかる。**武器庫では14種の攻撃手段をコインで購入・個別に強化し、どれか1つを装備して出撃**(マジックボルト/斧/ミサイル/オーブ/炎/氷/連鎖雷/毒/落雷/砲台/レーザー/メテオ/虹/ブレス)
6. **もっと遠くへ**: 敵は時間と初期地点からの距離で強くなる。周回を重ねて強化しないと先へは進めない

### 実績と解放

- **実績**は撃破数・仲間数・距離・ボス/リーパー討伐・素材収集・オブジェクト破壊・港/基地・死んだ回数など多角的に17種
- 実績を達成すると**新しい強化項目**(各施設に🔒表示)や**新スキル**が解放される
- **前提つき武器**: 上位の攻撃手段は別の武器を育てないと買えない(例: プリズムレーザー⇐ボルトLv4、メテオ⇐落雷Lv3)。「虹の奔流」は実績でのみ解放
- **レア要素**: 虹色に輝くレインボースライム、金色の琥珀の古木、真珠貝など。**そこでしか手に入らない素材**を落とす
- **周回中のマップ**: 最初の基地を解放するとNPCから古い地図をもらう。魂の広場の書庫の強化**「古い地図の修復」**を買うとマップが使えるようになる。地図には**次の拠点がひとつだけ**「?」で記されている。その拠点も解放すると、NPCが島の全容を語り**主大陸の基地と港がすべて**マップに記される。地形は**行ったことのある場所だけ**記録され(周回をまたいで蓄積)、それ以外の基地・港は**近くまで行って発見するまで表示されない**

### 世界の広がり

- **エリア別素材**: バイオームごとに「よく採れる素材」があり(進入時にバナー表示)、敵は得意素材を2倍落とし、通常持っていない素材もボーナスドロップする。狙いのスキルのために遠征する価値がある
- **超広大な世界**: 初期の島だけで半径26,000(端まで徒歩約4分)。大陸は多重リング構造(第1環10万→小島17万→第2環26万→第3環52万→最果て80万)。健脚・帆の改良・ワープゲートを重ねないと遠くへは行けない
- **バイオーム別BGM**: エリア(草原/灼熱/砂漠/魔界/氷原/密林/海など)ごとに曲が変わる
- **基地とクエスト**: 全21か所。未解放の基地に近づいてEを押すとNPCとの会話が始まる(会話中は時間停止)。依頼を受けたら**そのまま本編のマップで達成**する ― 特定の敵の討伐(依頼中は対象が湧きやすくなる)/その場での防衛/素材とコインの納品。達成したらNPCに**報告**すると解放される。解放した基地は死に戻り後の**転送ゲート**(最初からある)から**出撃地点として選べる**ほか、**基地のマップへ移動**できる。基地のマップには**3種類の特別強化施設** ― **武練場**(攻撃系)/**生命の祠**(生存系)/**秘宝の蔵**(経済・仲間・特殊)― が立ち、品揃えは基地ごとに違う
- **船の修理も同様**: 壊れた船を調べると船大工との会話が始まり、材料と手間賃をその場で渡すと修理してくれる
- **NPCとの再会話**: 解放した基地にはNPCが住みつき、話しかけると豆知識をくれる。さらに**2段階目の追加依頼**(❗マーク)があり、クリアするとコイン・素材、そして**クエスト限定スキル**(「老兵の誓い」「遺跡の加護」)が解放される
- **敵の強化ランク**: 時間・距離で強くなった敵はオーラをまとう(白→金→赤→紫)
- **港と船**: 大陸の沿岸8方位に港があり、それぞれ船大工のクエスト(コイン+素材の納品)をこなすと海に出られる
- **海と大陸**: 敵には陸専用/海専用/両生がいて、仲間も同じ。乗船中、陸の仲間は港で待機(逆も同様)。海の先には強敵が待つ**別大陸**が複数
- **ヒーラー敵**: 回復役の敵は距離を保って逃げる。移動速度を強化して追い詰めろ。倒せば仲間になり、今度は君を回復してくれる
- **終焉の刻**: 30分を過ぎるとリーパーの大群が出現しほぼ強制ゲームオーバー。だが死に戻り強化を極めれば……その先へ

## 🖼 キャラ画像の差し替え

すべてのキャラは仮置きの自動生成スプライトです。
`assets/img/` にPNGを置くだけで差し替えられます。**→ 一覧と手順は [ASSETS.md](ASSETS.md)**

## 📁 構成

```
index.html      エントリ(UI DOM)
css/style.css   スタイル
js/data.js      全バランスデータ(素材/スキル/敵/メタ強化/基地/港)
js/sprites.js   仮置きスプライト生成+画像差し替え
js/audio.js     効果音シンセ
js/save.js      セーブ(localStorage)
js/input.js     キーボード+仮想スティック
js/world.js     オープンワールド地形/オブジェクト/ミニマップ
js/skills.js    周回内スキルシステム+パネルUI
js/run.js       周回シーン(戦闘・AI・船・港・基地)
js/hub.js       魂の広場(恒久強化・ワープ)
js/main.js      ゲームループ/状態管理
ASSETS.md       画像アセット一覧(差し替え用)
```

バランス調整はほぼ `js/data.js` だけで完結します。
